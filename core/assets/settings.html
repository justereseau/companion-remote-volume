Remote Volume

Connection
Access
If set, clients must connect to ws://host:port/?token=<token>
One per line. Companion and other native clients need no entry. Empty rejects every web page.
Outside changes
Picks up changes made outside the app (media keys, the OS mixer). Commands are always pushed to all clients.
Apps
Lets clients list and control the apps playing audio. They can then see which apps those are.
Software updates
Checks once a day. Installing restarts the app, so clients disconnect for a moment.
